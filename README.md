## Overview

**NodeRaid** is a cyberpunk onchain strategy game where players build and defend digital bases called **Nodes**, raid rival systems, collect resources, and compete for dominance across the network.

The game is inspired by base-building and raiding strategy games, but reimagined with a hacker warfare theme: players protect their **Mainframe**, deploy cyber defenses, place traps, send raiders, and earn rewards through successful tactical gameplay.

NodeRaid is deployed on **Monad Testnet** and is designed around fast, low-cost, onchain interactions.

---

## What Is NodeRaid?

In NodeRaid, each player controls a cyber base known as a **Node**.

A Node contains:

- A central **Mainframe**
- Defensive structures
- Resource buildings
- Traps
- Attacker units
- Onchain progression
- Raid history
- Player-owned game state

The core idea is simple:

> Build your cyber base, defend your Mainframe, raid rival Nodes, and earn rewards.
